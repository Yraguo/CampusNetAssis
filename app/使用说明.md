# 校园网助手

安卓调试版，最低支持 Android 6.0。安装包位于 `artifacts/校园网助手.apk`。此版本不是应用商店正式签名版。

## 先部署 Cloudflare

此版本已默认填写 https://buct-campus-relay-237239.pages.dev 。如果需要部署自己的新服务，可使用 Cloudflare 账户部署本文件夹中的 `cloudflare` Worker（使用 SQLite Durable Object）。在安装了 Node.js、能访问 npm 和 Cloudflare 的电脑中打开 PowerShell：

```powershell
cd "E:\Gary\北京化工大学\校园网\app\cloudflare"
npx wrangler login
npx wrangler deploy
```

按 Wrangler 提示登录并选择账户；部署完成后记下输出的 HTTPS Worker 地址，例如 `https://buct-campus-connect.你的子域.workers.dev`。如果该名称被占用，可以在 wrangler.toml 修改 name 后再部署。创建及使用 Workers/Durable Objects 受账户套餐和 Cloudflare 当时的配额、计费规则约束。服务部署与手机登录均需实际测试。

官方文档：https://developers.cloudflare.com/workers/wrangler/commands/#deploy

此服务允许知道地址的人创建随机记录，公开使用时应在 Cloudflare 配置限流并监控用量；请勿开启记录请求体的日志。Worker 只保存密文和写入令牌的哈希。分享码同时是解密密钥；服务地址与分享码仅发送给可信任的人。



当前 APK 默认使用 Cloudflare Pages 备用入口，由它通过服务绑定转发到原有 Worker，继续使用相同的加密数据。校园网对该域名的可访问性需要在手机上实际验证。

## 账户拥有者

1. 手机连接移动数据或其他可以上网的网络，打开应用，进入“我是账户拥有者”。
2. 确认应用中预填的 Worker 地址，填写校园网账号和密码，点击“加密并上传”。
3. 上传成功后，把显示的服务地址和分享码发给被授权使用的人。拥有者本机同时保存账号，以后可以使用一键登录。
4. 校园网密码发生变化时，用同一台拥有者手机重新上传；使用者需要再次点击同步。清除本机数据或卸载会丢失上传权限令牌，届时需重新创建分享码并重新分享。

## 使用者

1. 在可访问互联网时，进入“我是使用者”，确认预填的服务地址，填写分享码并同步。
2. 通过应用打开 Wi-Fi 设置，手动连接校园 Wi-Fi。
3. 返回应用点击“一键登录校园网”。应用打开 `https://tree.buct.edu.cn` 的真实认证页面，尝试填入账号密码并点击登录；最终结果以学校页面显示为准。
4. 若认证前无法访问 Cloudflare，已同步的本机账号仍可用于登录。密码更新后，需重新联网同步一次。

## 注意

- 账号密码在手机上通过 Android Keystore 加密保存，备份已关闭；上传前使用随机密钥和 AES-GCM 加密。拥有分享码的人可解密并获取完整密码，且已经同步的副本无法从对方设备远程撤回。
- 本版本不会自动选择 Wi-Fi、绕过安卓网络设置，也不会声称认证一定成功；校园网站点或手机网络策略变化时自动填写可能失效。
- 如果学校认证页证书无效、网络劫持或页面跳转到其他域名，应用不会忽略证书错误，也不会向其他域名自动提交密码。
- 如果无法连接云端、校园网认证或手机限制应用使用网络，请检查服务是否部署、地址、手机网络和学校认证页面。实际校园网络、手机型号及账户设备数量限制需要现场验证。
- 源码在 `android` 和 `cloudflare` 文件夹；项目不会预置校园网凭据、Cloudflare 密钥或分享码。
